# 📖 Справочник команд Makefile

## 🚀 Основные команды скрапинга

### `make scrape`
**Главная команда для скрапинга аренды в Москве**
- Resilient режим с умными retry
- 1000 записей, 12000 страниц
- Параллелизм: 3 потока
- Задержки: 2-6 секунд
- Пауза после капчи: 15 минут

### `make scrape-sale`
**Скрапинг продажи квартир в Москве**
- Оптимизирован для объявлений о продаже
- Меньше параллелизма (2 потока)
- 8000 страниц для обхода

### `make scrape-spb`
**Скрапинг аренды в Санкт-Петербурге**
- 500 записей, 6000 страниц
- Увеличенные задержки (2.5-7 сек)
- 2 потока для стабильности

### `make scrape-test`
**Быстрый тест (100 записей)**
- Для проверки работоспособности
- 1 поток, короткие задержки
- 500 страниц максимум

## 🛡️ Специальные режимы

### `make scrape-safe`
**Максимальная надежность**
- 1 поток для минимального следа
- Большие задержки (3-8 секунд)
- 25 минут пауза после капчи
- 15 попыток на URL

### `make scrape-bulk`
**Большие объемы (2000+ записей)**
- 20000 страниц для обхода
- Повышенные задержки
- Расширенные настройки retry

### `make scrape-legacy`
**Старый режим без улучшений**
- Точно как было раньше
- Без retry, без восстановления
- Для сравнения производительности

## 🔧 Автоматизация

### `make build`
**Сборка исполняемого файла**
```bash
go build -o scrape_yandex.exe ./cmd/scrape_yandex
```

### `make scrape-auto`
**Автоматический режим с мониторингом**
- Запускает `monitor_scraper.bat`
- Автоматические перезапуски
- Отслеживание прогресса

### `make scrape-quick`
**Быстрый запуск с оптимальными настройками**
- Использует `run_resilient_scraper.bat`
- Берет настройки из `.env.resilient`

## 🎯 Специальные сценарии

### `make scrape-multi-cities`
**Последовательный сбор по городам**
- Москва → СПб → Екатеринбург
- Автоматические паузы между городами
- Разные лимиты для каждого города

### `make scrape-debug`
**Отладочный режим**
- Подробные логи
- 50 записей для тестирования
- Режим debug

### `make scrape-one`
**Скрапинг одной страницы**
```bash
make scrape-one URL="https://realty.yandex.ru/offer/123456/"
```

## ⚙️ Конфигурация

### `make setup-config`
**Создание файла настроек**
- Создает `.env.resilient` с оптимальными параметрами
- Настройки для аренды в Москве
- Готов к использованию

### `make show-config`
**Показать текущие настройки**
- Выводит содержимое `.env.resilient`
- Проверка активной конфигурации

### `make scrape-help`
**Справка по параметрам**
- Показывает все доступные флаги
- Описания параметров
- Значения по умолчанию

## 📊 Примеры использования

### Стандартный сбор аренды:
```bash
make scrape
```

### Тестирование настроек:
```bash
make scrape-test
```

### Максимальная осторожность:
```bash
make scrape-safe
```

### Сбор в другом городе:
```bash
make scrape-spb
```

### Отладка проблем:
```bash
make scrape-debug
```

## 🔄 Полный workflow

1. **Настройка:**
   ```bash
   make setup-config    # Создать конфигурацию
   make show-config     # Проверить настройки
   ```

2. **Тестирование:**
   ```bash
   make scrape-test     # Проверить работу
   ```

3. **Основной сбор:**
   ```bash
   make scrape          # Запустить основной сбор
   ```

4. **Автоматический режим:**
   ```bash
   make scrape-auto     # Для длительного сбора
   ```

## 💡 Советы

- **Для ежедневного сбора:** `make scrape`
- **Для тестирования:** `make scrape-test`
- **При проблемах с блокировками:** `make scrape-safe`
- **Для больших объемов:** `make scrape-bulk`
- **Автоматический режим:** `make scrape-auto`

Все команды используют улучшенный resilient scraper с автоматическим восстановлением и умными retry!
