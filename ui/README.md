# RentAdvisor - Нейросетевой прогноз стоимости аренды

Система оценки стоимости аренды квартир в Москве на основе машинного обучения.

Дипломный проект РТУ МИРЭА | Кафедра информационных технологий

## Описание

RentAdvisor - это веб-приложение для оценки рыночной стоимости аренды квартир в Москве. Система использует нейронные сети для анализа множества факторов и предоставляет точный прогноз стоимости аренды с доверительным интервалом.

### Основные возможности

- **Точный прогноз** - Нейронная сеть обучена на тысячах объявлений о аренде в Москве
- **Диапазон уверенности** - Получение точечного прогноза и доверительного интервала цены
- **Сопоставимые объекты** - Сравнение прогноза с реальными предложениями на рынке
- **PDF отчеты** - Генерация подробных отчетов с визуализацией
- **История оценок** - Сохранение и просмотр всех созданных оценок

## Технологический стек

- **Framework**: Next.js 13 (App Router)
- **UI**: shadcn/ui + Tailwind CSS
- **Иконки**: Lucide React
- **Типизация**: TypeScript
- **Темизация**: Dark Mode по умолчанию

## Настройка окружения

### Переменные окружения

Создайте файл `.env.local` в корне проекта:

```env
NEXT_PUBLIC_API_BASE_URL=http://localhost:8080
```

Измените URL на адрес вашего backend API сервера.

## Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для production
npm run build

# Запуск production сборки
npm start
```

Приложение будет доступно по адресу: http://localhost:3000

## API интеграция

Приложение интегрируется со следующими API эндпоинтами:

### Проверка здоровья ML сервиса
```
GET /api/v1/validation/ml-health
```

### Создание новой оценки
```
POST /api/v1/valuation/address
Content-Type: application/json

{
  "address": "Нежинская улица, 1к1",
  "city": "Москва",
  "rooms": 2,
  "area_total": 90,
  "area_living": 65,
  "area_kitchen": 20,
  "floor": 24,
  "floors_total": 31,
  "year_built": 2008,
  "house_material": "монолит",
  "condition": "евро",
  "with_text": true
}
```

### Получение списка оценок
```
GET /api/v1/valuation?limit=20&offset=0
```

### Получение оценки по ID
```
GET /api/v1/valuation/{id}
```

### Скачивание PDF отчета
```
GET /api/v1/valuation/{id}/pdf
```

## Особенности реализации

### ML Status Indicator
- Автоматическая проверка статуса ML сервиса каждые 30 секунд
- Визуальная индикация состояния (онлайн/офлайн/проверка)
- Влияние на параметр `with_text` при создании оценок

### Форма оценки
- Валидация обязательных полей
- Поддержка необязательных параметров
- Dropdown для выбора состояния квартиры
- Автоматическое заполнение города (Москва)

### Отображение результатов
- Прогноз с доверительным интервалом
- Характеристики объекта
- Текстовый анализ (при доступности ML сервиса)
- Список сопоставимых объектов со ссылками
- Кнопка скачивания PDF отчета

### Список оценок
- Табличное отображение всех сохраненных оценок
- Клик для просмотра детальной информации
- Модальное окно с полными данными оценки
