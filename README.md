# RentAdvisor

Нейросетевой сервис прогноза стоимости аренды квартир в Москве. Включает парсинг объявлений, ML-пайплайн (LightGBM), REST API и веб-интерфейс с админ-панелью.

## Архитектура

```
┌────────────┐     ┌──────────────┐     ┌───────────────┐     ┌──────────────┐
│   Next.js  │────▶│  Go Backend  │────▶│  Python ML    │     │  PostgreSQL  │
│   UI :3000 │     │  Gin  :8080  │     │  FastAPI :8000│────▶│  PostGIS     │
│            │     │              │────▶│  LightGBM     │     │  :5432       │
└────────────┘     └──────────────┘     └───────────────┘     └──────────────┘
                          │                                          ▲
                          │              ┌───────────────┐           │
```

## Быстрый старт

### 1. Предварительные требования

- **Go** 1.24+
- **Python** 3.10+ с `venv`
- **Node.js** 18+
- **Docker** и **Docker Compose**

### 2. Запуск инфраструктуры

```bash
# Из корня проекта — поднять PostgreSQL (PostGIS) и Redis
docker-compose up -d
```

### 3. Настройка переменных окружения

Создайте файл `go_back/.env`:

```env
# Сервер
PORT=8080
ENV=development

# PostgreSQL
POSTGRES_DSN_URL=postgres://user:password@localhost:5432/rentadvisor?sslmode=disable

# ML-сервис
ML_SERVICE_URL=http://localhost:8000
ML_TIMEOUT_SEC=100

# Яндекс Геокодер (опционально)
YANDEX_GEO_API_KEY=ваш_ключ

# Redis (опционально)
REDIS_ADDR=localhost:6379
REDIS_PASSWORD=
REDIS_DB=0

# ===== Админ-панель =====
ADMIN_KEY=ваш_секретный_ключ
PROJECT_ROOT=C:/Users/ваш_путь/fqw-rentAdvisor
# Или указать отдельно:
# SCRAP_DIR=C:/Users/ваш_путь/fqw-rentAdvisor/scrap
# REALVAL_DIR=C:/Users/ваш_путь/fqw-rentAdvisor/realval
```

Создайте файл `realval/.env`:

```env
POSTGRES_DSN_URL=postgres://user:password@localhost:5432/rentadvisor?sslmode=disable
REALVAL_MODEL_PATH=models/artefacts/rent_lgbm.joblib
```

### 4. Подготовка Python-окружения

```bash
cd realval
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # Linux/Mac
pip install -r requirements.txt
```

### 5. Запуск сервисов

```bash
# Терминал 1 — ML-сервер
cd realval
venv\Scripts\activate
uvicorn realval.http_app:app --reload --port 8000

# Терминал 2 — Go-бэкенд
cd go_back
go run ./cmd/service

# Терминал 3 — UI
cd ui
npm install
npm run dev
```

Или через корневой Makefile:

```bash
make doc          # Docker (БД + Redis)
make ml-start     # ML-сервер
make go-start     # Go-бэкенд
make ui-start     # UI
```

После запуска:
- **Сайт:** http://localhost:3000
- **Админ-панель:** http://localhost:3000/admin
- **API:** http://localhost:8080
- **Swagger:** http://localhost:8080/swagger/index.html

## Админ-панель

Доступна по адресу **http://localhost:3000/admin**. Для входа используется ключ из переменной `ADMIN_KEY`.

### Вход

1. Откройте http://localhost:3000/admin
2. Введите ключ администратора (значение `ADMIN_KEY` из `go_back/.env`)
3. Нажмите «Войти»

### Вкладки

#### 📊 Данные

Показывает количество записей в базе данных:
- **Аренда / Продажа** — активные объявления в таблице `listing`
- **Сырые** — необработанные записи в `listing_raw`

Кнопка «Обновить» загружает актуальные цифры.

#### 🕷️ Скрапинг

**Запуск парсинга** объявлений с Яндекс.Недвижимость:

1. Выберите тип сделки — **Аренда** или **Продажа**
2. Настройте параметры:

| Параметр | По умолчанию | Описание |
|---|---|---|
| Город | `moskva` | Город для парсинга |
| Страницы | `100` | Сколько страниц выдачи обойти |
| Макс. объявлений | `1000` | Лимит собранных записей |
| Параллелизм | `2` | Количество параллельных потоков |
| Мин. задержка | `1200ms` | Минимальная пауза между запросами |
| Макс. задержка | `2000ms` | Максимальная пауза |
| Макс. пустых стр. | `2` | Сколько пустых страниц до остановки |
| Макс. повторов | `3` | Повторы при ошибках |
| Captcha cooldown | `2m` | Пауза после капчи |

3. Включите **«Использовать куки»**, если хотите авторизованный парсинг
4. Нажмите **«Запустить скрапинг»** — откроется панель с логами в реальном времени

**Команды обработки** выполняются после парсинга:

| Команда | Описание |
|---|---|
| Нормализация | Приведение сырых данных к единому формату |
| Миграция | Обновление схемы БД |
| Геокодирование | Определение координат по адресам |
| Дедупликация | Удаление дубликатов |
| Обогащение | Добавление метро, расстояний, плотности |
| Деактивация | Пометка устаревших объявлений |
| Фикс последовательностей | Исправление auto-increment sequences |
| Полный пайплайн | Нормализация → Обогащение → Дедупликация (последовательно) |

#### 🧠 ML Пайплайн

Полный цикл обучения модели **LightGBM** — выполняйте шаги **последовательно сверху вниз**:

| # | Шаг | Описание |
|---|---|---|
| 1 | **Экспорт данных** | Выгружает rent-объявления из PostgreSQL в `data/raw/listings_rent.parquet` |
| 2 | **Загрузка и очистка** | Фильтрация выбросов, коэрсия типов → `data/interim/clean.parquet` |
| 3 | **Генерация признаков** | H3-индексы, rooms_bucket, локальная статистика → `data/features/base.parquet` |
| 4 | **Разделение** | Train/Valid split (по дате, 15 дней) → `data/splits/` |
| 5 | **Обучение** | Обучение LightGBM с интервалами → `models/artefacts/rent_lgbm.joblib` |
| 6 | **Тестовый прогноз** | Предсказание на `sample_object.json` → `models/reports/predict_sample.json` |

Кнопка **«Перезапустить ML-сервер»** — остановит текущий uvicorn и запустит заново (подхватит новую модель).

#### 📋 Задачи

- Список всех запущенных и завершённых задач
- Статусы: 🔵 Выполняется, ✅ Завершено, 🔴 Ошибка, 🟡 Остановлено
- Клик по задаче открывает **логи в реальном времени** (SSE-стрим)
- Кнопка **«Остановить»** для принудительной остановки
- Автообновление пока есть running-задачи

#### ⚙️ Настройки

**Редактор куки** для авторизованного парсинга:

1. Текущие куки загружаются из файла `scrap/.env.resilient`
2. Чтобы обновить:
   - Откройте realty.yandex.ru в браузере, авторизуйтесь
   - Экспортируйте куки расширением **«Get cookies.txt»** (Netscape-формат)
   - Вставьте содержимое в текстовое поле
   - Нажмите **«Сохранить куки»**
3. При запуске скрапинга включите переключатель «Использовать куки»

## Типичный рабочий процесс

### Первичный сбор данных и обучение

```
1. Админ → 🕷️ Скрапинг → Запустить скрапинг (rent) → дождаться завершения
2. Админ → 🕷️ Скрапинг → Полный пайплайн (нормализация + обогащение + дедупликация)
3. Админ → 📊 Данные → проверить количество записей
4. Админ → 🧠 ML Пайплайн → выполнить шаги 1-6 по порядку
5. Админ → 🧠 ML Пайплайн → Перезапустить ML-сервер
6. Перейти на сайт — прогнозы работают!
```

### Обновление данных

```
1. Скрапинг (новые объявления)
2. Полный пайплайн
3. Экспорт → Ingest → Features → Split → Train
4. Перезапуск ML-сервера
```
